# Contributing Guide 🤝

Welcome! We're excited that you want to contribute to this demo repository. This guide will help you get started.

## Getting Started

### 1. Fork the Repository (Optional)

If you want your own copy, click the "Fork" button on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/Demo-Repo.git
cd Demo-Repo
```

### 3. Set Up Remote (if forked)

```bash
git remote add upstream https://github.com/heyad/Demo-Repo.git
```

## Making Changes

### Create a Branch

Always create a new branch for your work:

```bash
git checkout -b descriptive-branch-name
```

**Branch naming conventions:**
- Use lowercase and hyphens
- Be descriptive: `add-john-doe`, `fix-typo-readme`, `update-contributors`

### Make Your Changes

- Edit existing files or create new ones
- Follow the existing code style
- Keep changes focused and small

### Commit Your Changes

Write clear, descriptive commit messages:

```bash
git add .
git commit -m "Add clear description of what you changed"
```

**Good commit messages:**
- ✅ "Add Jane Smith to contributors list"
- ✅ "Fix typo in README installation section"
- ✅ "Update Git commands table"

**Bad commit messages:**
- ❌ "Update"
- ❌ "Fixed stuff"
- ❌ "asdf"

### Push Your Changes

```bash
git push origin your-branch-name
```

## Creating a Pull Request

1. Go to the repository on GitHub
2. Click "Pull requests" → "New pull request"
3. Select your branch
4. Fill in the PR template with:
   - **Title**: Brief description of your changes
   - **Description**: What you changed and why
5. Click "Create pull request"

## Pull Request Guidelines

- Keep PRs small and focused
- Reference any related issues
- Be patient while waiting for review
- Be open to feedback and suggestions

## Code of Conduct

- Be respectful and inclusive
- Help others learn
- Ask questions if you're unsure
- Have fun learning Git and GitHub!

## Questions?

If you have questions, feel free to:
- Open an issue
- Ask your instructor
- Check the [GitHub Docs](https://docs.github.com)

Thank you for contributing! 🎉
