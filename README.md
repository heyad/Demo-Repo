# Demo-Repo 🚀

Welcome to the Demo Repository! This is a beginner-friendly repository designed to help students learn how to work with Git and GitHub.

## 📚 What You'll Learn

- How to clone a repository
- How to create and switch branches
- How to make commits
- How to push changes
- How to create pull requests
- How to collaborate with others

## 🚀 Getting Started

### Prerequisites

- Git installed on your computer ([Download Git](https://git-scm.com/downloads))
- A GitHub account ([Sign up here](https://github.com/join))

### Step 1: Clone the Repository

```bash
git clone https://github.com/heyad/Demo-Repo.git
cd Demo-Repo
```

### Step 2: Create a New Branch

Always create a new branch for your changes:

```bash
git checkout -b your-name-feature
```

### Step 3: Make Changes

Edit files or create new ones. For example, add your name to `CONTRIBUTORS.md`:

```bash
echo "- Your Name" >> CONTRIBUTORS.md
```

### Step 4: Stage and Commit Your Changes

```bash
git add .
git commit -m "Add your descriptive commit message here"
```

### Step 5: Push Your Changes

```bash
git push origin your-name-feature
```

### Step 6: Create a Pull Request

1. Go to the repository on GitHub
2. Click "Pull requests" → "New pull request"
3. Select your branch and click "Create pull request"
4. Add a title and description
5. Click "Create pull request"

## 📖 Common Git Commands

| Command | Description |
|---------|-------------|
| `git status` | Check the status of your working directory |
| `git branch` | List all branches |
| `git checkout -b <branch>` | Create and switch to a new branch |
| `git add <file>` | Stage a file for commit |
| `git add .` | Stage all changed files |
| `git commit -m "message"` | Commit staged changes |
| `git push origin <branch>` | Push commits to remote |
| `git pull` | Pull latest changes from remote |
| `git log` | View commit history |
